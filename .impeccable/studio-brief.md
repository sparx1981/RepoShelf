# Studio surface brief

Mode: Operate, with a gallery for browsing original backgrounds.

RepoShelf helps people building with AI assistants find resources. Studio extends the existing black, lime, DM Sans and Manrope identity; its first viewport demonstrates a real background editor rather than a marketing hero. Keep the shared navigation and profile menu. Tools work locally after loading. Uploads remain local and are excluded from shared links. Every supported download and code-copy action requires sign-in; the server checks existing current-legal-acceptance rules. Public recipes and previews are intentionally public and do not promise secrecy.

Confirmed scope: gradient/mesh, colour ramps, ASCII/dither, and 100 original curated procedural backgrounds first. Later, 120 AI images in 12 categories, generated offline through the current image tool. No generation API, API key, paid service upgrade or new serverless function. User delegated curation to the assistant. Original PNGs and enlarged WebPs are allowed. Private downloads use the existing Supabase project jccogltqhkffuderukrj, on its free plan.

The Impeccable launcher is unavailable. Incumbent visual authority: dist/style.css, dist/fonts.css, dist/ui.html, dist/ui.css and dist/profile-menu.js. No design world replacement. Screenshots and verification are in .impeccable/review/. No detector ran because the launcher is unavailable.

Signature interaction: directly move mesh points on the canvas, or use the labelled keyboard sliders; edit a selected library recipe in the same gradient builder. Reduced motion disables background drift. Contrast feedback is sampled from the preview, without promising text accessibility for arbitrary content. Avoid blank states in shipped browsing: Images stays hidden until private assets and public thumbnails are verified.

## Direction contract

THESIS: give builders a working, local visual editor, with original assets they can reuse.
OWN-WORLD: inherit RepoShelf's near-black ground (#0b0b0d), lime accent (#d6fb79), DM Sans body, Manrope headings, restrained borders and shared profile menu.
STORY: adjust the live preview, compare colour or ASCII output, browse presets, then sign in for an export or save.
FIRST VIEWPORT: Studio title and purpose, four discoverable tool/library tabs, a large real mesh preview, editable controls, and export actions.
FORM: direct extension of the existing UI library inside its confirmed visual world and approved scope. The Impeccable launcher and concept-seed script are absent in this environment; no comp or replacement visual identity was requested or generated. Code-led implementation.
