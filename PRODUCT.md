# RepoShelf product context

RepoShelf is a resource catalogue for people building software with AI assistants. It combines public GitHub projects and demos, prompts, and UI components. Public browsing and previews help visitors decide what to use; signed-in account features include My collection and access to supported code and downloads.

Studio adds local browser tools for gradients and meshes, eleven-step colour ramps, and ASCII/dither conversion, followed by an original background catalogue. Its established RepoShelf visual identity comes from dist/style.css, fonts.css, ui.html and profile-menu.js. Studio must extend that identity, retain keyboard access and reduced-motion support, and keep uploaded images on the visitor's device.

The owner approved all three tools and 100 curated procedural backgrounds first, followed by 120 offline AI images across twelve categories. All downloads require sign-in. Original PNGs and enlarged WebP variants are included. The assistant performs curation. Generation uses the image tool already available in the conversation; there is no generation API or key. Zero additional setup cost is a hard constraint, including storage within the existing free Supabase plan. RepoShelf's existing project is jccogltqhkffuderukrj. Public thumbnails and recipes are public by design; supported exports and private image downloads use the account gate and current legal acceptance where configured.

Reviewed AI image batches publish as they become ready; the first batch has 20 images across all twelve categories. Every original PNG and download WebP must be verified in private storage before its public catalogue entry is published. The animation control includes a speed slider, and ASCII text fitting uses measured glyph bounds.
